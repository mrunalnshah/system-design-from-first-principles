# T-01.08: Build-time math with KaTeX 0.19.1

## Goal
Typeset `$…$` and `$$…$$` at build time (HTML + MathML), with unknown commands as build errors at their exact line.

## Interface to honour
remark-math + a rehype step calling `katex.renderToString(tex, { throwOnError: true, output: "htmlAndMathml", displayMode })`; E-MATH with line and column; self-hosted KaTeX CSS.

## Acceptance tests
- REQ-READ-008.AC1: Given `$\frac{1}{10^3}$`, when the page is shown with JavaScript off, then the fraction is typeset.
- REQ-READ-008.AC2: Given a command the math renderer doesn't support, such as Chapter 1's current `$\micro s$`, when the build runs, then it stops with a build error naming the file and line and suggesting `\mu` (CNF-001, decided at G2).
- REQ-READ-008.AC4: Given `$\mu s$`, when it's rendered, then it shows "μs".
- REQ-CNT-005.AC1: Given Chapter 1 (after the author's `\mu` edit, CNF-001), when it's rendered, then `$\frac{1}{10^3}$` and `$\mu s$` appear as typeset math, not raw text.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/markdown/plugins/math.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.
