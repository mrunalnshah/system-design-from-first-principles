# T-01.19: Full-screen diagram viewer

## Goal
Select a diagram to open it full screen on the theme background, with zoom (pinch, wheel, + and −) and pan, closed by Escape with focus returned; without JS it's a link to the SVG.

## Interface to honour
Binds to `[data-diagram]` figures; a `<dialog>` with @panzoom/panzoom 4.6.2; loaded only on pages with figures.

## Acceptance tests
- REQ-DIAG-003.AC1: Given a phone, when the reader taps a diagram, then it opens full screen and can be pinch-zoomed to 400%.
- REQ-DIAG-003.AC2: Given the full-screen view is open, when the reader presses Escape, then it closes and focus returns to the diagram.
- REQ-DIAG-003.AC3: Given JavaScript is off, when the reader selects a diagram, then the SVG opens on its own in the same tab.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.
