# T-03.06: Drawing sources stay private (tests)

## Goal
Prove the gitignore rule covers drawing sources and that no Excalidraw source ever lands in `dist/`.

## Interface to honour
Uses `git check-ignore` and a scan of `dist/`.

## Acceptance tests
- REQ-DIAG-006.AC1: Given `part-1_foundations/excalidraw/01_computer-architecture.excalidraw.md`, when `git status` runs after it's saved, then the file is ignored (`.gitignore` rule).
- REQ-DIAG-006.AC3: Given the built site, when its files are listed, then none is an Excalidraw source.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- tests/drawings-private.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Changing .gitignore beyond adding a missing pattern.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
