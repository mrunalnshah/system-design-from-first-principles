# T-02.06: Homepage: featured chapters and latest articles

## Goal
Up to 6 featured chapters (or "Start here"), and up to 5 latest articles with featured ones first, matching the preview.

## Interface to honour
`selectFeaturedChapters(book)`, `selectLatestArticles(articles)`; `<ChapterCard>`; `<ArticleRow>` (in MOD-articles, used by the archive too).

## Acceptance tests
- REQ-HOME-002.AC1: Given Chapters 1 and 3 are featured, when the homepage is built, then two cards appear, Chapter 1 first.
- REQ-HOME-002.AC2: Given no chapter is featured, when the homepage is built, then the section shows the first three published chapters, titled "Start here" instead of "Featured chapters".
- REQ-HOME-002.AC3: Given 8 featured chapters, when the homepage is built, then the first 6 in book order show, followed by an "All chapters" link to the contents page.
- REQ-HOME-003.AC1: Given articles dated 2026-10-01 and 2026-11-01, when the homepage is built, then the November article comes first.
- REQ-HOME-003.AC2: Given an older article with `featured: true`, when the homepage is built, then it comes first, marked "Featured".
- REQ-HOME-003.AC3: Given no published articles, when the homepage is built, then the section and its link are left out entirely.
- REQ-CNT-004.AC3: Given a draft is also `featured: true`, when the homepage is built, then it doesn't appear.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/home/select.test.ts`
- `npm --prefix .site run test:e2e -- tests/e2e/home.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: home) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
