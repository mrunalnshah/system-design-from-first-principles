# T-01.11: Screen test harness: screenshots, axe, JS off (TOOL-09)

## Goal
Enabling: Playwright projects for light/dark × JS on/off at 320, 768 and 1280 px, with helpers for axe, horizontal scroll and same-origin requests, before the first screen task.

## Interface to honour
Helpers `expectNoA11yViolations(page)`, `expectNoHorizontalScroll(page)`, `expectOnlySameOriginRequests(page)`, `expectNoCookies(context)`; `webServer` runs `astro preview` on the fixture vault.

## Acceptance tests
- TOOL-09.AC1: Given a page with an image missing alt text, when the harness runs, then the axe helper fails naming the rule.
- TOOL-09.AC2: Given a page wider than 320 px, when `expectNoHorizontalScroll` runs at 320 px, then it fails.
- TOOL-09.AC3: Given a page that requests a third-party URL, when `expectOnlySameOriginRequests` runs, then it fails naming the URL.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/helpers.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Any screen's own tests.
