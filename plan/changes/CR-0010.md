# CR-0010: The link check allows article pages until T-03.01 builds them
Status: approved (2026-11-27, option 1 of CNF-009) · Date: 2026-11-27 · Raised by: T-02.06's Verify (R-12)

(CR-0009 is the number already reserved for the open contract write-up logged in R-10 and R-11.)

## Why
CR-0008 let the link check allow exactly the pages the header and footer link to before they exist (`articles/`,
`about/`), on the assumption that nothing else links ahead of the plan. T-02.06 (R-12) makes the homepage's latest
articles link to each published article, as REQ-HOME-003 and the ArticleRow component require, but article pages
only arrive in T-03.01 (R-13). The fixture vault publishes `articles/why-caches.md`, so TOOL-12.AC2's test finds
`articles/why-caches/` broken and the publish workflow's checks would fail. The author's vault has no articles yet,
so readers see no broken link. Recorded as CNF-009.

## What
MODIFIED `plan/tools.md` TOOL-12, Does: while a page isn't built yet, the check allows the addresses the plan
links to ahead of it, and nothing else: Articles and About (CR-0008), and **ADDED** a published article's own
address, `articles/<slug>/`, until T-03.01 builds article pages. An allowed address is allowed only while its
`index.html` is missing, as before.

MODIFIED `plan/tasks/T-03.01.md` (not started): Done when gains "the link check no longer allows article pages
(TOOL-12, CR-0010): TOOL-12.AC2's test expects only the not-yet-built pages that remain". Its files list stays as
it is (size S allows 3): like T-02.03 dropping `book/` from the allowance, the removal in `.site/tools/links.ts` and
its test is logged wiring outside the packet. Points unchanged. Note for T-03.01: ArticleRow already
writes dates as "1 November 2026" in UTC (REQ-READ-009.AC1), so the article page can share that formatting.

Code (T-02.06): `.site/tools/links.ts` allows `articles/<slug>/` (one path segment under `articles/`) while it isn't
built, alongside NOT_YET_BUILT; `.site/tools/links.test.ts` expects the fixture's `articles/why-caches/` among the
allowed addresses, and that `articles/x/y/` is still reported.

`specs/conflicts.md` CNF-009: resolved by this CR.

## Impact
`<tools> impact .site/tools/links.ts .site/tools/links.test.ts plan/tasks/T-03.01.md`: no feature, module or
requirement owns these paths; the task touched is T-01.20 (done, not reopened: its packet's CR-0008 note stays as
history, and TOOL-12's text in plan/tools.md carries the rule now). No rounds, points or scope change.
