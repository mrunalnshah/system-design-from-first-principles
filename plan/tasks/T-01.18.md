# T-01.18: Margin notes: layout and phone toggle

## Goal
Footnotes float beside their lines at 1100 px and wider (CSS only); on phones a script turns each marker into an `aria-expanded` toggle.

## Interface to honour
Binds to `[data-note]` markers and `.sidenote` spans from T-01.10.

## Acceptance tests
- REQ-READ-006.AC1: Given a footnote on a 1280 px screen, when the page is shown, then the note's top is level with its reference line and doesn't overlap the previous note.
- REQ-READ-006.AC2: Given a 375 px screen, when the reader taps marker 1, then the note opens below that line; tapping again closes it.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/margin-notes.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: chapter, article) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
