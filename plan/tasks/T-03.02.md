# T-03.02: All-articles archive

## Goal
Every article newest first, grouped by year, with "Undated" last and a friendly empty state.

## Interface to honour
`groupByYear(articles)`; `<ArticlesArchive articles>`.

## Acceptance tests
- REQ-ART-002.AC1: Given articles from 2025 and 2026, when the archive is built, then a "2026" group comes before "2025".
- REQ-ART-002.AC2: Given no published articles, when the archive is built, then it says "No articles yet. Start with the book." with a link to Chapter 1.
- REQ-ART-002.AC3: Given 200 articles, when the archive is built, then they're all on one page (no pagination needed for a static list this size), and the page stays within the NFR-002 budget.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/articles/group.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: articles) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
