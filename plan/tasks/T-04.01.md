# T-04.01: Security review

## Goal
Careful: walk the threat model and checklist: CSP on every page with no violations, no inline scripts, same-origin-only requests, no cookies, workflow permissions and SHA pins, gitleaks clean, audit clean. Record the results in security.md.

## Interface to honour
None new.

## Acceptance tests
- NFR-008: Privacy: No cookies, no browser storage of personal data, and no third-party requests at all: fonts and scripts are self-hosted, and there's no analytics (G3) (measured by: End-to-end test listing every request and cookie on each page; every request goes to the site's own origin)

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/security.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- New features.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
