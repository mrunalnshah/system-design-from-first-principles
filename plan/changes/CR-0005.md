# CR-0005: Authoring workflow: one-step sync, drawing embeds, writing guide
Status: approved (2026-11-26) · Date: 2026-11-26 · Raised by: the user, before R-05

## Why
The user's direction (2026-11-26):
1. "A sync type tool or script I can call which will generate all required items and deploy the push for new updates."
2. "I will only write parts, chapters and draw diagrams. Each part folder will have chapters, a diagram folder, an
   excalidraw folder. Generate images from Excalidraw … so the HTML can read and display them based on theme."
3. "A guide for writing (a template), and using the system to the max."
Choices made in chat: drawing embeds are swapped at build time (chapter files are never rewritten); Obsidian's
auto-export makes the SVGs and sync checks they're present and fresh; images live in each part's `diagram/` folder;
sync runs from a double-clickable `sync.cmd` or `npm --prefix .site run sync`.

## The author's workflow after this change
```
part-<n>_<slug>/
├── chapter-<n>_<slug>.md      ← you write; embed drawings as ![[<name>.excalidraw|Caption]]
├── excalidraw/<name>.excalidraw.md   ← you draw (gitignored, your own backup)
└── diagram/<name>-light.svg, <name>-dark.svg   ← sync puts Obsidian's exports here
```
Write and draw in Obsidian, save, then double-click `sync.cmd`. Sync collects the images, checks every drawing is
exported and current, builds the site, shows what changed, asks for a one-line message, commits and pushes. The
site is live a few minutes later.

## What
ADDED `specs/features/authoring.md` (FEAT-authoring):
- **REQ-AUTH-001 One-step publish (sync).** WHEN the author runs sync THE SYSTEM SHALL pull new remote commits
  (fast-forward only), collect diagram images (REQ-AUTH-002), check every drawing is exported and current, build the
  site, show what changed, ask for a one-line message, then commit and push to main, stopping before any commit at
  the first problem, with a plain-language message. Criteria AC1–AC6: commit + push of a new chapter with its
  images; stops on a stale drawing; stops on a build error; "Nothing new to publish" makes no commit; pulls first and
  explains a pull it can't do; prints the Actions link and the site address.
- **REQ-AUTH-002 Images collected into diagram/.** Sync moves Excalidraw's `excalidraw/<name>.excalidraw.light.svg`
  and `.dark.svg` into the same part's `diagram/` as `<name>-light.svg` and `<name>-dark.svg`, replacing older
  copies. A drawing with no images, or only one theme, or images older than the drawing, stops sync and names it with
  "open it in Obsidian and save it (Ctrl+S)". Criteria AC1–AC3.
- **REQ-AUTH-003 Writing guide and templates.** `WRITING-GUIDE.md` at the vault root, and `templates/` (chapter,
  article, book.md, about.md) covering every frontmatter key, every supported syntax, diagrams, drafts, featured
  items, renaming (`moved_from`), sync, and what each sync or build message means, marking what's live and what's
  coming. Criteria AC1–AC3: every frontmatter key from the contract is documented and in a template; every build
  message code is explained; `templates/` is never published.

ADDED to `specs/features/diagrams.md`:
- **REQ-DIAG-007 Drawing embeds become themed images.** `![[<name>.excalidraw|Caption]]` renders the
  `<name>-light.svg`/`<name>-dark.svg` pair from the vault's diagram folders (closest first) as one themed figure,
  without reading the gitignored drawing source. AC1: figure with caption; AC2: no images anywhere →
  E-DRAWING-NOT-EXPORTED naming entry, line and drawing.
