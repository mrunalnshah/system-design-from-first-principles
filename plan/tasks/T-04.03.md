# T-04.03: Every build message has a seeded test

## Goal
Close NFR-013: every code in build-messages.md has a broken-vault fixture, and the harness passes.

## Interface to honour
None new.

## Acceptance tests
- NFR-013: Author-friendly errors: Every build error names the file, the line and the fix in plain words; a broken diagram embed blocks the publish, while an optional field that's missing only warns (measured by: Tests that seed each error and check the message)

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- tests/messages.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.
- W-EMPTY-BOOK is emitted by the vault scan and has its fixture; `UNOWNED` in `.site/tests/messages.test.ts` is empty (CR-0011).
