# T-00.06: Secret scanner in pre-commit and CI (TOOL-13)

## Goal
Enabling: the repository is public (CNF-003), so a leaked secret must be blocked before commit and caught in CI.

## Interface to honour
`npm --prefix .site run setup-hooks` installs the hook. The CI job downloads gitleaks v8.30.1 from its GitHub release, verifies the checksum and runs `gitleaks detect`.

## Acceptance tests
- TOOL-13.AC1: Given a staged file containing a fake AWS-style key from gitleaks' own test fixtures, when committing, then the hook blocks the commit.
- TOOL-13.AC2: Given the CI job, when it runs on the repository, then it passes on a clean history.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.
