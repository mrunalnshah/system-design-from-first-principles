# T-04.05: Restore drill, runbooks and launch checklist

## Goal
Release readiness: run the restore drill from a fresh clone, measure the publish time over the last runs, confirm $0 costs, finish the runbooks, and write the launch checklist: GitHub 2FA, branch protection, Pages source, both Excalidraw auto-export settings, and the author's own backup of the gitignored drawing sources.

## Interface to honour
None.

## Acceptance tests
- NFR-005: Publish time: Push to live in ≤ 10 minutes at the 95th percentile (measured by: Timestamps of the CI deploy job)
- NFR-007: Cost: $0 a month for hosting and builds (measured by: GitHub Pages and GitHub Actions for a public repository (specs/stack.md); checked at each phase review)
- NFR-012: Availability: No server of our own; the site is static files on the host's CDN, and any host outage is the host's (measured by: Monthly check by the author that the site loads; noted in operations.md)

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.
- NFR-005, NFR-007 and NFR-012 each have a guard test tagged `@req` in `.site/tests/workflow.test.ts` (CR-0013).

## Out of scope
- Anything that changes the product.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
