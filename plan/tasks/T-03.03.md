# T-03.03: About page

## Goal
Render `about.md` when it exists; otherwise the header's name links to the portfolio, with W-ABOUT-MISSING.

## Interface to honour
`getPage("about")`.

## Acceptance tests
- REQ-SITE-003.AC1: Given `about.md`, when the site is built, then `/about/` shows its contents in the reading view.
- REQ-SITE-003.AC2: Given no `about.md`, when the site is built, then there's no About page, the header's name links to the portfolio instead, and the build prints a warning.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/about.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: about) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Writing about.md: that's the author's.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
