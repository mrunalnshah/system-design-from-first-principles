# CR-0001: Drop stalled dependencies; prefer the platform and our own small code
Status: approved (2026-11-26) · Date: 2026-11-26 · Raised in: T-00.01 (R-01)

## Why
`npm --prefix .site install` failed: eslint-plugin-jsx-a11y 6.10.2 accepts only ESLint ≤ 9, while eslint-plugin-astro 3.2.1 requires ESLint ≥ 10. The user's direction (2026-11-26): "don't depend on dead things; write code which is future-proof." So every dependency was audited for maintenance (npm registry and GitHub API, 2026-11-26).

| Dependency | Last release / last commit | Finding |
|---|---|---|
| eslint-plugin-jsx-a11y 6.10.2 | 2024-10 / stalled | No ESLint 10 support. The fork `-x` 0.2.0 is young. **Remove both.** |
| github-slugger 2.0.0 | 2022-10 / 2023-09 | Finished, unmaintained; about 10 lines of logic. **Replace with our own `slugify()`.** |
| tsx 4.23.15 | 2026-09, one maintainer | Node 26 runs TypeScript natively (verified locally: `node main.ts` with types and `.ts` imports). **Remove; run `node tools/cli.ts`.** |
| remark-math 6.0.0 | 2023-11; repo active 2025-02 | A thin wrapper over micromark-extension-math (2025-11) and mdast-util-math (2026-11), in the same unified collective Astro uses. **Keep.** |
| Everything else | active within the last 3 months; not archived | Keep (astro, katex, vitest, playwright, axe, lhci, eslint, typescript-eslint, eslint-plugin-astro, prettier, dependency-cruiser, linkinator, panzoom, fontsource). |

## What
1. REMOVED: eslint-plugin-jsx-a11y (and no fork). Accessibility stays guarded by axe-core in every screen and state (TOOL-09), the token contrast check (TOOL-08) and the full a11y suite (T-04.04).
2. REMOVED: github-slugger. MOD-obsidian-markdown owns `slugify(text)`: lowercase, strip punctuation except `-`, spaces → `-`, de-duplicate with `-1`, `-2` (the same rule GitHub uses), covered by unit tests (T-01.09).
3. REMOVED: tsx. Tools run on Node 26's built-in type stripping: `"tools": "node tools/cli.ts"`. Tool code uses only erasable TypeScript syntax (`erasableSyntaxOnly` in tsconfig), and relative imports carry `.ts` extensions (`allowImportingTsExtensions`).

## Impact
- Files: `.site/package.json`, `.site/tsconfig.json` (T-00.01); `specs/stack.md` (rows and notes); `specs/modules.md` (MOD-obsidian-markdown dependencies); `plan/tools.md` (header: language/runtime); `specs/standards.md#tooling`; packet T-01.09 (slug function instead of github-slugger).
- No requirement, criterion or round changes. Points are unchanged (T-01.09 stays S/2: a 10-line function with tests).
