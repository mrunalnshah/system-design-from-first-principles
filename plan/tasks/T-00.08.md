# T-00.08: Thin slice live: url(), base layout and 404 on Pages

## Goal
The first end-to-end slice: a placeholder homepage and 404 built through `url()` and deployed live at https://mrunalnshah.github.io/system-design-from-first-principles/. Then check CNF-005 live (request an unknown address; record the status code and whether the friendly page shows) and delete `.site/spikes/`.

## Interface to honour
`url(route: Route): string` and `absoluteUrl(route)` as in specs/contracts/interfaces.md; `<BaseLayout title description route>` with `<html lang="en">` and the skip link.

## Acceptance tests
- REQ-SITE-013.AC1: Given base path `/system-design/`, when the site is built, then the Chapter 1 link is `/system-design/book/computer-architecture/`, and no built page has an internal link or asset without the prefix.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/site/url.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: home, not-found) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
