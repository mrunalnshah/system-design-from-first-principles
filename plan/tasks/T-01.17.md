# T-01.17: Chapter menu: sticky panel, phone sheet, scrollspy

## Goal
The sticky chapter menu with a scrollspy on wide screens, a `<dialog>` sheet with a focus trap on phones, and a plain list without JavaScript.

## Interface to honour
Markup hooks `data-chapter-menu`, `data-sections-button`; the script binds when present and honours reduced motion.

## Acceptance tests
(CR-0008) REQ-READ-002.AC1's test in tests/e2e/reader.spec.ts opens the site menu until now; extend it to open this chapter menu.

- REQ-READ-007.AC1: Given a 1280 px screen, when the reader scrolls into section 1.2, then "Limitations" is highlighted in the panel.
- REQ-READ-007.AC2: Given a 375 px screen, when the reader taps the menu button, then the panel opens, focus moves into it, and Escape closes it and returns focus to the button.
- REQ-READ-007.AC3: Given JavaScript is off, when a chapter is shown, then the section list appears as a plain list under the title, and still works.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.
