# T-03.07: Base path at the root, and failed builds never deploy

## Goal
Prove the site still links correctly with base `/` (custom-domain readiness), and that a broken embed leaves the live site unchanged.

## Interface to honour
A test build with `--base /` plus the link check; a workflow test on a branch with a seeded broken embed.

## Acceptance tests
- REQ-SITE-013.AC2: Given the base path changes to `/`, when the site is rebuilt, then every link still resolves (the link check passes).
- REQ-SITE-007.AC2: Given a push with a broken embed, when the run finishes, then the live site is unchanged, and the run page shows the REQ-CNT-007 error message.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- tests/base-root.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Changing the real base path.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
