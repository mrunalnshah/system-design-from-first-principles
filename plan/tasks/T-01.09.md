# T-01.09: Heading demotion, section numbers and anchors

## Goal
The vault's `#`/`##` become h2/h3 numbered 1.1 / 1.1.1 for chapters (unnumbered for articles), with stable anchors from our own `slugify()` (GitHub's rule; CR-0001).

## Interface to honour
Driven by `ctx.headingNumbers: { prefix } | false`; fills `RenderResult.sections`.

## Acceptance tests
- REQ-READ-004.AC1: Given Chapter 1's headings "Components", "Disk", "RAM", "Limitations", when it's shown, then they read 1.1 Components, 1.1.1 Disk, 1.1.2 RAM, 1.2 Limitations.
- REQ-READ-004.AC2: Given a chapter, when it's rendered, then the chapter title is the only `h1`, and the vault's `#` headings are `h2`.
- REQ-BOOK-002.AC2: Given the heading "Moore's Law", when it's published, then its anchor is `#moores-law`.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.
