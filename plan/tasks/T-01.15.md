# T-01.15: Site shell: header, footer, theme, metadata, CSP

## Goal
What every page shares: the header with title, author and portfolio, the footer, the theme from `prefers-color-scheme` with no flash, metadata and Open Graph, the sitemap, and the CSP meta tag, matching the design preview.

## Interface to honour
`<BaseLayout title description route ogImage?>` renders `<SiteHeader>` and `<SiteFooter>`; `headTags(page)` returns the title, description, canonical, OG and CSP tags.

## Acceptance tests
- REQ-SITE-001.AC1: Given `author: "Mrunal Nirajkumar Shah"` and `author_url: "https://mrunalnshah.github.io/"` in `book.md`, when any page is built, then the header shows both.
- REQ-SITE-001.AC2: Given a 375 px screen, when the header is shown, then it fits on one row, with Contents, Articles and the portfolio link in a menu.
- REQ-SITE-001.AC3: Given the portfolio link, when it's followed, then it opens in the same tab and is marked as an external link for screen readers.
- REQ-SITE-002.AC1: Given a reader in dark mode, when any page loads, then the dark theme shows with no flash of the light theme.
- REQ-SITE-005.AC1: Given Chapter 1, when it's built, then its title is "Computer Architecture · System Design from First Principles".
- REQ-SITE-005.AC2: Given a draft, when the sitemap is built, then the draft isn't in it.
- REQ-SITE-008.AC1: Given a build in 2026, when any page is built, then the footer reads "© 2026 Mrunal Nirajkumar Shah".

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/shell.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: home, chapter, contents, article, articles, about, not-found) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Page bodies.
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
