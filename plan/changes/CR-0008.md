# CR-0008: The contracts R-09's loader, shell and reader settled
Status: approved (2026-11-27, option A) · Date: 2026-11-27 · Raised by: the R-09 review

## Why
R-09 wired the vault loader, the site shell and the reader layout. To keep the modules apart and the pages working,
it changed some public interfaces beyond what specs/contracts/interfaces.md and specs/modules.md say. The review
accepted each change, and asked for the contracts to be updated so the next tasks build on the real ones.

## What
MODIFIED `specs/contracts/interfaces.md`:
- MOD-vault: `vaultLoader(options: { vaultRoot: string; figures: () => Promise<FigureRenderer>; collection: "chapters" | "articles" | "pages" | "book" }): Loader`.
  The figure renderer is handed in by `content.config.ts`, so MOD-vault never imports MOD-diagrams. Adds
  `readVault(root)` (the vault as data) and `buildVault(options)` (rendered), the loader's pure core, for tests and
  the build-message harness. `getBook()` returns `{ settings, parts, chapters, totalReadingMinutes }`, each chapter
  with its `html`.
- MOD-site: `<BaseLayout title description route? ogImage? book current? section? type?>`. `book` carries the title,
  author and portfolio from book.md (MOD-site can't read the vault). `current` marks the header link for this page
  (`aria-current="page"`), and `section` the one whose section the page is in (`aria-current="true"`). Adds
  `stopOnErrors()` (the loader stops a build right after content sync on any content error), `buildRun()` (the
  current Astro command and run, so caches are per run), and `headTags(page)`.
- MOD-reader: `<ReaderLayout kind>`, `<ChapterTitle chapter>`, `<Epigraph text source?>` as built.

MODIFIED `specs/modules.md`:
- MOD-vault "Depends on: … MOD-site (`url()`, the build-issue collector, `stopOnErrors`, `buildRun`)", no longer
  "type only".
- MOD-obsidian-markdown also writes each heading's anchor link beside it (`<div class="heading">`) and makes display
  math focusable, for REQ-READ-004.AC3 and axe's scrollable-region rule.

MODIFIED `design/tokens.json` (done in R-09): the font stacks lead with the self-hosted variable fonts' family names
("Inter Variable", "Source Serif 4 Variable", "JetBrains Mono Variable"), without which the bundled fonts never
apply. The look is unchanged.

MODIFIED `plan/tasks/T-01.17.md` (chapter menu), Acceptance: REQ-READ-002.AC1's test (reduced motion) must open the
chapter menu itself; until T-01.17 it opens the site menu.

MODIFIED `plan/tasks/T-01.20.md` (performance guards): the header and footer link to Contents, Articles and About
(REQ-SITE-001, REQ-SITE-008), whose pages arrive in R-11 and R-13. The link check must allow exactly those three
addresses until their pages exist.

Comment in `.site/.dependency-cruiser.cjs`: the open question about content → diagrams is settled (dependency
inversion through content.config.ts).
