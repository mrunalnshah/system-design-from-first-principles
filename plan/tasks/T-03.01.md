# T-03.01: Article page

## Goal
Articles at `/articles/<slug>/` in the calm reader (no numbering, no chapter menu), with date, reading time and end links.

## Interface to honour
`getStaticPaths` from `getArticles()`; `<ReaderLayout kind="article">`.

## Acceptance tests
- REQ-ART-001.AC1: Given `articles/why-caches.md`, when it's published, then its address is `/articles/why-caches/`.
- REQ-READ-009.AC1: Given an article dated 2026-11-01, when it's shown, then the date reads "1 November 2026".

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test:e2e -- tests/e2e/article.spec.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: article) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
- The link check no longer allows article pages (TOOL-12, CR-0010): TOOL-12.AC2's test expects only the not-yet-built pages that remain.

## Out of scope
- The archive (T-03.02).
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
