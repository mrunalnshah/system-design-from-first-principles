# T-01.04: Frontmatter schemas, book.md settings and drafts

## Goal
Validate every frontmatter field at the boundary with plain-language errors, read book.md, and keep drafts off the site.

## Interface to honour
zod schemas mirroring contracts/frontmatter.schema.json; `readBookSettings(root)`; E-BOOK-MISSING, E-FRONTMATTER-YAML, E-FRONTMATTER-FIELD, W-ARTICLE-UNDATED with broken-vault fixtures.

## Acceptance tests
- REQ-CNT-011.AC1: Given `book.md` with `title`, `author` and `author_url`, when the build runs, then the header, hero and footer use them.
- REQ-CNT-011.AC2: Given no `book.md`, when the build runs, then it stops with "book.md is missing at the vault root. Create it with at least a title and an author." and an example.
- REQ-CNT-011.AC3: Given `author_url` that isn't an https address, when the build runs, then it stops with an error naming the field.
- REQ-CNT-007.AC1: Given invalid YAML in a chapter's frontmatter, when the build runs, then it stops with "part-1_foundations/chapter-1_…md line 3: the frontmatter isn't valid YAML. Check for a missing colon or quote."
- REQ-CNT-004.AC2: Given a draft article, when the build runs, then no page exists at its address and it's in no list.
- REQ-CNT-003.AC3: Given an article without `date`, when the build runs, then it publishes, sorts after dated articles, shows no date, and the build prints a warning naming the file.
- TOOL-15.AC1: Given the fixture `broken/E-BOOK-MISSING`, when the harness runs, then the build fails with E-BOOK-MISSING and the fix text from build-messages.md.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/content/schemas.test.ts src/features/content/book-settings.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`

## Done when
- Every acceptance test passes and both reviews pass.

## Out of scope
- Homepage use of the featured flag (T-02.06).
- Editing the author's vault files (`book.md`, `about.md`, `part-*/`, `articles/`, `.obsidian/`).
