# T-01.13: Figure renderer and diagram asset routes

## Goal
One `<picture>` per pair (dark source + light img, sized from the viewBox, lazy below the fold), served at hashed `/diagrams/` addresses; small diagrams fill the text column, wide ones break out to 900 px.

## Interface to honour
`createFigureRenderer(index): FigureRenderer`; `diagramAssetPaths(index)`; `<DiagramFigure file alt eager>`.

## Acceptance tests
- REQ-DIAG-002.AC1: Given a 916 px wide SVG on a 1280 px screen, when it's shown, then it's 900 px wide and centred, breaking out of the 70-character text column.
- REQ-DIAG-002.AC2: Given a 490 px wide SVG, when it's shown on a 1280 px screen, then it's shown at its natural width or the text-column width, whichever is larger, and stays crisp.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/diagrams/figure.test.ts`
- `npm --prefix .site run lint` and `npm --prefix .site run check`
- `npm --prefix .site run lint:boundaries`
- `npm --prefix .site run tools -- check`
- Compare the result with `design/preview/index.html` (screens: chapter) at phone (375 px) and laptop (1280 px) width, in light and dark

## Done when
- Every acceptance test passes and both reviews pass.
