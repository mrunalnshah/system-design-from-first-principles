# T-01.10: Footnotes as margin-note markup

## Goal
Render each footnote twice: as an inline `.sidenote` span and in the standard end list, so margin notes work on wide screens and without JavaScript.

## Interface to honour
Marker `<a class="ref" href="#fn-n" data-note="n">`; `<span class="sidenote" role="note" id="sn-n">`; end list `<section class="endnotes">`.

## Acceptance tests
- REQ-READ-006.AC3: Given JavaScript is off, when the page is shown on a phone, then the notes are listed at the end of the entry, and each marker links to its note.

## Steps
1. Write the interface comment and signatures.
2. Write one failing test per criterion, each tagged `@req <criterion-id>`.
3. Implement until the tests pass.
4. Run Verify and log the output.

## Verify
- `npm --prefix .site run test -- src/features/markdown/plugins/footnotes.test.ts`
